# Website architecture notice

The active KOREK architecture and consensus code are maintained in [Korek-Network/blockchain](https://github.com/Korek-Network/blockchain).

The current Planck testnet policy is a 210,000,000 KRK cap, zero genesis premine, 60-second reward blocks, a 50 KRK initial subsidy, halvings every 2,100,000 reward blocks, 95% of each subsidy to the successful miner, 5% to the public treasury, and 100% of transaction fees to the successful miner.

This repository retains an early local prototype for historical development context, but its legacy chain implementation is not the public Planck network and must not be used as the source of current network parameters.

See the canonical [architecture](https://github.com/Korek-Network/blockchain/blob/main/docs/ARCHITECTURE.md), [mining guide](https://github.com/Korek-Network/blockchain/blob/main/docs/MINING_AND_NODE.md), and [public explorer](https://scan.planck.korek.network).
