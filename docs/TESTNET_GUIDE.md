# KOREK Planck testnet guide

The current guide is maintained with the active blockchain:

[Open the Planck mining and node guide](https://github.com/Korek-Network/blockchain/blob/main/docs/MINING_AND_NODE.md)

For ordinary testnet mining, install [KOREK Miner](https://github.com/Korek-Network/korekUI/releases/tag/korekui-testnet-latest) and use `https://rpc.planck.korek.network` for both the mining gateway and blockchain API. A local node is not required.

Planck is unaudited testnet software. Test KRK has no monetary value and will not migrate to mainnet.
