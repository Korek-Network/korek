QUICK START

From download to your first block.

Keep your node running while using the desktop miner. The app guides you through the rest.

  1. 01
    Install KOREK Miner

    Choose the correct package above and open the application.

  2. 02
    Create or open a wallet

    Securely save the encrypted wallet file and 24-word recovery phrase.

  3. 03
    Connect your node

    Use miner port 9833 and blockchain API port 8365.

  4. 04
    Choose compute devices

    Select CPU threads and detected GPUs, then press Start mining.

  5. 05
    Monitor rewards

    Accepted blocks and spendable wormhole rewards appear in the dashboard.
