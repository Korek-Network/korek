COMMON QUESTIONS

Know before you run it.

Planck is an engineering testnet. It is not the KOREK mainnet and its tokens have no financial value.

Is KOREK mainnet live?

No. Planck is a prototype testnet. Public P2P consensus, audited security and production GPU job verification are still under development.

Can I mine test KRK?

Yes. Create a wormhole account in KOREK Wallet and follow the node and mining guide. Planck rewards are test-only.

Is KOREK quantum-proof today?

No blockchain should make that claim without audited implementation. KOREK’s roadmap targets a hybrid migration using standardized post-quantum signatures.

Where can I inspect transactions?

Run the Planck node and open KOREKSCAN at the node’s explorer port. It displays blocks, transfers, addresses, fees and confirmations.
